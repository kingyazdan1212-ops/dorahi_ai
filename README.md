# دوراهی (Dorahi) — نسخه نهایی

**شبیه‌ساز هوشمند تصمیم‌های زندگی با پشتیبانی از هوش مصنوعی واقعی**

## ویژگی‌ها

### هوش مصنوعی واقعی
- پشتیبانی از هر API سازگار با OpenAI (OpenAI، OpenRouter، Groq، Together و ...)
- تنظیمات کلید API، Base URL و مدل از داخل خود سایت
- اگر کلید نباشد یا خطا رخ دهد، خودکار به موتور هوشمند داخلی سوییچ می‌کند

### موتور هوشمند داخلی (آفلاین)
- تشخیص ۷ دسته موضوع (شغلی، عاطفی، مهاجرت، تحصیلی، مالی، سلامت، خانواده)
- سناریوهای باکیفیت از پیش طراحی‌شده

### تجربه کاربری
- کاملاً فارسی و راست‌چین
- طراحی تاریک مدرن
- تاریخچه تصمیم‌ها (localStorage)
- مثال‌های آماده
- دکمه بازتولید و اشتراک‌گذاری
- Progressive Web App (قابل نصب روی گوشی)

## نحوه استفاده از AI واقعی

1. روی دکمه **AI** در هدر کلیک کن
2. کلید API خودت را وارد کن
3. Base URL را انتخاب کن (OpenRouter پیشنهاد می‌شود چون CORS بهتری دارد)
4. مدل را مشخص کن (مثلاً `gpt-4o-mini` یا `llama-3.3-70b`)
5. ذخیره کن

> نکته: فراخوانی مستقیم بعضی APIها از مرورگر به خاطر CORS ممکن است محدود شود. OpenRouter معمولاً بهتر کار می‌کند.
